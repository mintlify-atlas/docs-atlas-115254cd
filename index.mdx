`anyhow` is a Rust library that provides `anyhow::Error`, a single flexible error type that works with any error implementing `std::error::Error`. It is designed for application code where you want easy, ergonomic error propagation without defining your own error types.

## Why anyhow?

Writing error handling in Rust applications often involves creating boilerplate error enums, implementing `From` conversions, and losing context as errors propagate up the call stack. `anyhow` solves this by providing one concrete error type that:

- Wraps **any** `std::error::Error` via `?` — no `From` impls needed
- Lets you **attach human-readable context** at each level of propagation
- Captures **backtraces automatically** on Rust ≥ 1.65
- Supports **downcasting** back to the original error type when needed

<Steps>
  <Step title="Add anyhow to Cargo.toml">
    ```toml Cargo.toml
    [dependencies]
    anyhow = "1.0"
    ```
  </Step>
  <Step title="Use anyhow::Result in your functions">
    ```rust
    use anyhow::Result;

    fn read_config(path: &str) -> Result<Config> {
        let content = std::fs::read_to_string(path)?;
        let config: Config = toml::from_str(&content)?;
        Ok(config)
    }
    ```
  </Step>
  <Step title="Attach context for better diagnostics">
    ```rust
    use anyhow::{Context, Result};

    fn load_app() -> Result<()> {
        let config = read_config("app.toml")
            .context("failed to load application configuration")?;
        Ok(())
    }
    ```
  </Step>
  <Step title="Handle errors in main">
    ```rust
    fn main() -> anyhow::Result<()> {
        load_app()?;
        Ok(())
    }
    ```
  </Step>
</Steps>

<Note>
  anyhow is intended for **application** code. If you are writing a library and want callers to receive structured, typed errors, consider [thiserror](https://github.com/dtolnay/thiserror) instead.
</Note>
